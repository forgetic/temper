# Start a development session

Use this checklist before editing so your context comes from the current
repository, not from stale chat history.

## Checklist

1. Confirm you are in the repository root: `/home/free/src/rust/harness`.
2. Read `README.md` for the human-facing overview.
3. Read `AGENTS.md` for the code and documentation orientation map.
4. Read `docs/README.md` and choose the task-relevant docs.
5. Read `docs/reference/agent-lessons/README.md` and any lessons whose tags
   match the task. For broad architecture or crate-boundary work, read all
   active lessons.
6. Read task-relevant reference, explanation, how-to, and ADR files before
   editing.
7. Run `git status --short`; treat existing changes as someone else's work
   unless you made them in this session.
8. Use `rg` to discover related code and docs instead of relying on
   conversation history.
