# Shared codebase-memory lifecycle

This maps feature `ai/temper#1280` under plan `ai/temper#1278`. It runs real
Forgejo, a host forgejo-runner, standalone Temper and two first-party engineer
jobs with an issue-specific gated Jig model.
Periodic cache retention is disabled in this fixture so A owns the cold start.
Concurrent HTTP gates hold the first requests before Jig's sequential server;
all model responses are still generated by Jig, including A's late response.

A's ordinary parent bootstrap frontend cold-starts the fake daemon. B joins the
same daemon and service-work process. The harness then withdraws A's exact
assignment and lease through the real Forgejo API. Normal worker heartbeats
produce ownership-loss cancellation and complete A's production process
containment. Standalone agents run in-process: the check identifies A's serving
MCP owner, requires its recursive-empty/reaped proof, then requires completed job
cancellation after all registered process owners have joined. The installed native
test separately covers outer subprocess Job containment. Only afterward may the same B attempt query the same daemon/work
process, consume exact local source, read the ordinary target, repair, validate,
and converge through real host Actions CI to merge and closure.

The fake models shared service work; native same-request index coalescing is
validated separately with the installed provider. Two different checkout roots
are not represented as identical native index requests.

The converger checks final-session daemon and helper natural exit while standalone
is still alive. This happens before the general manifest harness stops standalone.
The required read-only assertion checks the resulting closed facts, never creates
the cancellation or cleanup it is checking. Raw source, checkout roots and exact
PID/start identities remain in temporary private evidence. Published provider
facts contain only the closed checkpoint names, counts and booleans.

Run with `cargo dev-scenario-run scenarios/shared-codebase-memory-lifecycle`.
