# Scoped graph evidence

Mapped live validation for ai/temper#1279 under parent ai/temper#1278.
The fixture inherits the retry-affinity repository and real Forgejo/host runner,
standalone Temper and Jig topology. It consumes implementation, caller and
focused-test graph sources, then checks every cited path plus bounded src/tests
scopes after discovery convergence. A filesystem-only investigator receives the
structured Verify handoff, reads source, and returns attributed findings with
limitations. Temper revalidates coverage generation, current checkout and source
identity before and after that child. The parent performs its own ordinary exact
read before the minimal patch, focused validation, PR, CI, merge and issue closure.

The optional child enablement is explicit in this fixture's generated configuration;
production defaults and child model/permission selection remain unchanged.
Run `cargo dev-scenario-run scenarios/scoped-graph-evidence`.
